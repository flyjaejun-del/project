# 나이스 복무 입력 도우미 (크롬 확장 프로그램)

나이스 복무 신청 화면의 입력칸(복무구분, 기간, 시각, 사유, 행선지, 비상연락처)을 자동으로 채워 주는 크롬·웨일·엣지용 확장 프로그램입니다.

- 로그인(인증서)은 선생님이 직접 합니다. 프로그램은 비밀번호나 인증서를 다루지 않습니다.
- 칸만 채우고 상신(결재 요청)은 누르지 않습니다. 화면을 확인한 뒤 직접 상신해 주세요.
- 입력한 내용과 설정은 이 컴퓨터의 브라우저 안에만 저장되고 외부로 보내지 않습니다.

## 1. 설치하기

1. 이 `neis-bokmu-helper` 폴더를 컴퓨터에 내려받습니다(압축 파일이면 풀어 둡니다).
2. 크롬 주소창에 `chrome://extensions` 를 입력합니다. (웨일: `whale://extensions`, 엣지: `edge://extensions`)
3. 오른쪽 위 `개발자 모드` 를 켭니다.
4. `압축해제된 확장 프로그램을 로드합니다` 를 누르고 `neis-bokmu-helper` 폴더를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘에서 `나이스 복무 입력 도우미` 를 고정(핀)해 두면 편합니다.

## 2. 처음 한 번: 입력칸 연결하기

나이스 화면 구조는 교육청이나 업데이트 시기마다 조금씩 다를 수 있습니다. 그래서 처음 한 번은 "이 칸이 시작일 칸이야" 하고 직접 알려 줍니다.

1. 나이스에 로그인하고 `복무 > 복무신청` 입력 화면을 엽니다.
2. 확장 프로그램 아이콘 → `칸 연결 · 설정` 탭에서 날짜·시각 모양을 나이스 화면에 맞게 고릅니다.
   - 시각이 "시"와 "분" 두 칸으로 나뉘어 있으면 `시, 분이 따로 있음` 을 고릅니다.
3. `입력칸 연결 시작` 을 누르면 나이스 화면 오른쪽 아래에 안내창이 나옵니다.
4. 안내에 나오는 칸(복무구분 → 시작일 → 시작 시 → …)을 차례로 클릭합니다. 마우스를 올리면 주황색 테두리가 보입니다.
   - 연결하는 동안에는 클릭해도 나이스 화면이 반응하지 않으니 안심하고 누르세요.
   - 화면에 없는 칸(예: 행선지)은 `건너뛰기` 를 누릅니다.
5. `나이스 화면에 표시` 단추로 연결한 칸이 파란 테두리로 잘 잡히는지 확인할 수 있습니다.

## 3. 복무 입력하기

1. 나이스 복무 신청 화면을 열어 둡니다.
2. 확장 프로그램 아이콘 → `복무 입력` 탭에서 복무구분, 날짜, 시각, 사유 등을 적습니다.
3. `나이스에 입력하기` 를 누르면 칸이 채워지고, 칸마다 결과(입력됨 / 확인 필요 / 실패)가 표시됩니다.
4. 나이스 화면에서 내용을 확인하고 직접 상신합니다.

자주 쓰는 복무(예: 수요일 협의회 출장, 매달 병원 진료 조퇴)는 `저장` 해 두었다가 불러와 날짜만 바꿔 쓰면 됩니다.

## 4. 동료 선생님과 나누기

`파일로 내보내기` 로 만든 `나이스_복무_칸연결.json` 을 동료에게 주면, 동료는 `파일 가져오기` 만으로 칸 연결을 마칠 수 있습니다. 같은 교육청 나이스를 쓸 때 가장 잘 맞습니다. 이 파일에는 칸 위치 정보만 들어 있고 개인 정보는 들어 있지 않습니다.

## 5. 잘 안 될 때

| 증상 | 해결 방법 |
| --- | --- |
| "열린 나이스 화면이 없습니다" | 나이스(`*.neis.go.kr`)에 로그인한 탭이 있는지 확인합니다. |
| "칸을 못 찾음" | 복무 신청 입력 화면이 열려 있는지 확인합니다. 나이스가 바뀌었다면 칸을 다시 연결합니다. |
| 일부 칸만 빠짐 | `칸 사이 대기 시간` 을 800~1000으로 늘립니다. |
| 날짜가 이상하게 들어감 | `날짜 모양` 을 다른 형식으로 바꿔 봅니다. |
| 복무구분 "실패" | 확장 프로그램에 적은 이름이 나이스 목록의 글자와 똑같은지 확인합니다(예: `연가`). |

## 파일 구성

| 파일 | 하는 일 |
| --- | --- |
| `manifest.json` | 확장 프로그램 설정(나이스 주소에서만 동작) |
| `popup.html / popup.css / popup.js` | 아이콘을 눌렀을 때 나오는 입력·설정 화면 |
| `content.js` | 나이스 화면 안에서 칸 연결(클릭 학습)과 자동 입력을 처리 |
| `fields.js` | 입력칸 목록, 날짜·시각 변환 등 공통 정의 |

## 알아 두기

- 실제 나이스 화면이 아니라 나이스와 비슷하게 만든 모의 화면(프레임 안의 입력폼, 직접 만든 드롭다운 목록)에서 시험했습니다. 실제 나이스에서 처음 쓸 때는 결과를 꼭 눈으로 확인해 주세요.
- 학교나 교육청의 정보보안 지침에서 브라우저 확장 프로그램 설치를 제한하는지 먼저 확인해 주세요.
